# Ghost FTP 1.5.0

Release date: 2026-09-05

Ghost FTP 1.5.0 is a desktop-workspace, throughput, stability and release-discipline release. It keeps the privacy-first, zero-NuGet runtime model while improving the parts of the client that matter during long FTP/FTPS sessions: window/pane ergonomics, queue throughput, isolation between transfers and explicit platform boundaries.

## Premium resizable desktop workspace

The main Ghost FTP window now behaves more like a professional file-transfer workstation instead of a fixed dashboard.

- The Saved Servers sidebar can be resized horizontally.
- The Local and Remote file panes can be resized independently with a real WPF `GridSplitter`.
- The Transfers area can be resized vertically so users can dedicate more space either to file browsing or queue diagnostics.
- Double-clicking a splitter resets that region to a sensible default.
- The main window explicitly supports resize-with-grip behavior and uses a smaller safe minimum size.
- Responsive GridView column resizing is now actually wired during startup. The previous helper existed but was never connected to the main window lifecycle.
- Column widths are recalculated on both window and list-size changes, reducing clipped paths and unused whitespace.

This keeps the current Ghost FTP visual language while making the workspace substantially closer to the flexible two-pane ergonomics expected from mature desktop FTP clients.

## Parallel transfer engine

The transfer queue is no longer limited to a single worker.

- The queue now runs up to three transfers concurrently by default.
- The implementation supports a bounded concurrency range up to eight workers internally.
- Every real FTP/FTPS queue job still receives its own transfer session, preserving browser/control-channel isolation.
- Demo mode remains safe because its local session serializes operations behind its own session gate.
- The queue remains bounded at 4,096 jobs.
- Automatic retries remain limited to transient socket/timeout and FTP 4xx conditions.
- Authentication failures, permission failures, TLS failures and permanent FTP 5xx errors are still not retried blindly.
- Cancellation remains per-job and shutdown cancels all active workers deterministically.
- Disposal now awaits all worker tasks before releasing queue cancellation resources.

The objective is higher throughput without trading away protocol correctness or allowing one failed transfer to desynchronize another transfer or the browsing connection.

## Security and privacy guarantees retained

1.5.0 does not add any telemetry, analytics, crash-upload service, advertising SDK, background updater, cloud profile sync or tracking endpoint.

The FTP/FTPS security model remains strict:

- Explicit FTPS remains the default for new server profiles.
- Plain FTP requires a warning before connection.
- TLS 1.2/1.3 uses normal .NET certificate-chain and hostname validation.
- No certificate-validation bypass switch is provided.
- Passive data connections use the authenticated control host rather than trusting a server-provided PASV redirect host.
- CR/LF/NUL command injection guards remain enforced.
- FTP replies, listing payloads and recursive traversal are bounded.
- Download partial-file resume and `SIZE` verification remain enabled where supported.
- Uploads still use a temporary remote object, final-size verification and rollback-safe replacement flow.
- Saved passwords remain opt-in and Windows DPAPI-protected in the current Windows desktop client.

## Languages

Ghost FTP continues to ship 29 selectable languages with English as the primary language and guaranteed fallback:

English, Croatian, German, French, Spanish, Italian, Portuguese, Dutch, Polish, Czech, Slovak, Slovenian, Hungarian, Romanian, Bulgarian, Greek, Turkish, Ukrainian, Russian, Serbian, Bosnian, Swedish, Danish, Norwegian, Finnish, Japanese, Korean, Simplified Chinese and Traditional Chinese.

The application and Setup catalogs are local C# data. No online translation service is queried.

## Setup

The existing premium guided Setup architecture is retained:

**Language → License → Install options → Ready → Install/Update → Finish**.

The 1.4.2 live-language-switch crash fix remains part of the baseline. Setup continues to use the same installed `GhostFTP-Setup.exe` for maintenance/uninstall and does not install a service, scheduled task, separate updater or tracking component.

## Platform scope

The repository currently ships a production **Windows WPF desktop application** and a platform-neutral `GhostFTP.Core` FTP/FTPS engine targeting `net10.0`.

There are no Android or iOS application projects in the shipping source tree. Ghost FTP 1.5.0 does not add mobile targets.

A pixel-identical Linux GUI is **not claimed in 1.5.0**. WPF is Windows-only, and the project currently forbids third-party UI/runtime package dependencies. Shipping an allegedly identical Linux WPF binary would therefore be technically false. Linux parity is tracked as a separate desktop-renderer requirement while the FTP/FTPS core remains reusable on `net10.0`.

See `docs/PLATFORM-SUPPORT.md` for the exact contract.
