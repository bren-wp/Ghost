# Ghost FTP 1.7.0

Ghost FTP 1.7.0 is a desktop-workstation clarity release. It keeps the existing Ghost FTP visual identity and privacy/security model, but restructures the Windows client around a denser, easier-to-scan FTP layout inspired by the proven information hierarchy of professional dual-pane clients.

## Professional workspace layout

- Added a permanent top menu bar with **File, View, Sites, Transfers, Tools and Help** groups.
- Added a compact global action toolbar for Connect, Disconnect, Upload, Download, Refresh, New Folder, Rename, Delete, Site Manager, Settings and Diagnostics.
- Reorganized the main workspace into four predictable operating zones:
  1. Saved Sites sidebar;
  2. Connection Log + Quick Connect strip;
  3. Local / Remote dual-pane browser;
  4. Transfers queue.
- Reduced decorative vertical space and moved more of the available window area to file lists and transfer rows.
- Kept the Ghost FTP dark/light visual system, rounded surfaces, accent colors and native WPF editing semantics.
- Preserved real resizable splitters for sidebar/workspace, Local/Remote panes and browser/Transfers regions.
- Splitter double-click reset behavior and persisted workspace geometry remain supported.
- Raised the default desktop window size for the denser workstation while keeping a supported resizable minimum.

## Connection Log

- Added a dedicated local **Connection Log** panel directly in the main workspace.
- Log entries include local timestamps and concise event classes such as INFO, TLS, LIST, WARN, ERROR and DEMO.
- The log records startup, profile loading, local workspace readiness, connection attempts, TLS/plain connection state, directory listing completion, disconnects and user-visible failures.
- Passwords, protected credentials and file contents are never written to the log.
- Log history is bounded in memory and can be cleared by the user.
- Connection Log data is local UI state and is never uploaded to Ghost FTP, BRENDIGO LTD or an analytics service.

## Site Manager

- Added a first-class **Site Manager** window instead of relying only on one-profile-at-a-time Add/Edit dialogs.
- Saved sites are listed in a dedicated left navigation area.
- The right editor exposes the real supported profile fields: site name, host/IP, port, FTP/FTPS security mode, username, password, Remember password and default remote path.
- The Advanced section documents Ghost FTP's actual passive-mode behavior: EPSV preference, PASV fallback and authenticated-control-host data-channel hardening.
- Global timeout, retry, keepalive and concurrent-transfer settings remain centralized in Settings rather than being represented as fake per-site options.
- Built-in Demo remains visible but protected from modification/removal.
- Site Manager can save local changes or immediately connect to the selected site.
- Password persistence remains opt-in and continues to use the existing Windows DPAPI current-user protection path.

## File-list clarity

- Local and Remote lists use tighter workstation spacing and clearer table alignment.
- Remote rows now expose the server-provided permissions field when available.
- Name, Type, Size, Modified and Remote Permissions columns dynamically adapt to pane width.
- Existing path bars, filters, Local shortcuts, upload/download actions and context menus remain available.
- Multi-selection, drag-and-drop upload, keyboard navigation and focused destructive-action routing remain intact.

## Authentic repository screenshots

- Added a dependency-free `--capture-ui <directory>` application mode for documentation and CI.
- Documentation capture launches the real Ghost FTP WPF application, opens the built-in local Demo session, renders the actual production MainWindow and renders the actual Site Manager window.
- The capture path generates:
  - `ghostftp-client.png`;
  - `ghostftp-site-manager.png`.
- Capture mode forces the documented dark theme and English primary locale for deterministic repository images.
- Demo capture performs no FTP network connection, telemetry, analytics or external image-generation request.
- Repository screenshots are therefore generated from the real shipping UI rather than AI-generated mockups or third-party design tools.

## Security and privacy continuity

1.7.0 does not weaken the 1.6.0 transport or credential model.

- Explicit FTPS remains the default for new profiles.
- Plain FTP still requires an explicit warning.
- TLS certificate/hostname validation remains strict with no trust-all bypass.
- Passive data channels remain hardened against PASV host redirection.
- Control commands continue to reject CR/LF/NUL injection.
- Listing/reply/traversal resource bounds remain enforced.
- Download partial-file and upload temporary/rollback integrity behavior remains unchanged.
- Saved passwords remain optional and DPAPI protected.
- No telemetry, analytics, crash upload, advertising, cloud profile sync or hidden background updater was added.

## Platform scope

- Windows x64 and Windows ARM64 remain the production desktop GUI targets.
- `GhostFTP.Core` remains platform-neutral `net10.0` so a future Linux renderer can reuse the exact protocol/transfer engine.
- This version does not falsely claim a Linux GUI while the production presentation layer remains WPF.
- Android and iOS remain outside the shipping product scope.
