# Ghost FTP 1.4.1

Release date: 2026-09-05

Ghost FTP 1.4.1 is a focused publisher-identity and uninstall-cleanup hardening release. It does not change the FTP/FTPS protocol engine introduced and validated in 1.4.0.

## Publisher website identity

- Added `GhostBrand.PublisherWebsite` as the canonical BRENDIGO LTD website value.
- Product website remains **https://ghostftp.com**.
- Publisher/developer website is now explicitly **https://brendigo.com**.
- Product remains **Ghost FTP / GhostFTP**.
- Developer, publisher and licensor remains **BRENDIGO LTD**.
- Company number remains **16545639**.
- Registered office remains **71–75 Shelton Street, Covent Garden, London, WC2H 9JQ, United Kingdom**.
- Source audit now rejects builds where the product or publisher websites disappear from the central brand model.
- WPF smoke tests validate both HTTPS website values and the Ghost FTP / BRENDIGO LTD identity.

## Uninstall self-cleanup hardening

The installed `GhostFTP-Setup.exe --uninstall` remains the only uninstall implementation; no separate uninstaller executable is generated.

Version 1.4.1 strengthens cleanup when the uninstalling Setup executable is itself still running:

- Windows delete-on-reboot remains registered first as an eventual fallback;
- the hidden local cleanup helper now retries deletion for a bounded period instead of making only one early attempt;
- the helper can therefore tolerate a user remaining on the uninstall Finish page for several minutes;
- after Setup exits and Windows releases the executable lock, the helper removes the maintenance Setup executable and then attempts to remove the empty install directory;
- the wait uses loopback-only delay traffic and does not contact an external host.

This change improves uninstall completion without adding a second executable, service, scheduled task or background updater.

## Security and privacy impact

- No telemetry, analytics, tracking SDK, advertising SDK or crash upload was added.
- No background product/update network request was added.
- `brendigo.com` is metadata and a documented publisher website; adding it does not create an automatic background connection.
- Shipping source remains C#-only with zero NuGet `PackageReference` entries.
- Existing FTP/FTPS TLS, path, transfer-integrity and persistence boundaries are unchanged from 1.4.0.
