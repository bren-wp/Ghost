# Ghost FTP 1.3.1

Release date: 2026-09-05

Ghost FTP 1.3.1 was a focused regression, transfer-queue and persistence hardening release.

## Critical editable-input fix

- Removed fragile custom TextBox and PasswordBox replacement templates from the shared design layer.
- Restored native WPF editing semantics while preserving Ghost FTP typography, colors and spacing.
- Kept Host, Port, Username, Password, path and filter fields focusable, tab-accessible and writable.
- Added a real Windows/WPF editable-input smoke-test project.
- CI now instantiates shared TextBox, PasswordBox and ComboBox controls on an STA thread and verifies actual value mutation.
- Source audit blocks reintroduction of the known fragile input-template pattern.

## Transfer queue stability

- Added local exception boundaries around synchronous toolbar and context-menu actions.
- Added Retry selected, Cancel selected, Cancel all, Copy source, Copy destination and Clear finished queue actions.
- Queue saturation now creates a visible failed job instead of an unhandled UI exception.
- Removed version drift from CI artifact naming.

## FTP/FTPS hardening

- Added strict directory-listing payload memory limits before parsing.
- Kept deterministic data-stream/socket closure before final FTP replies.
- Stopped swallowing control-channel transport/protocol failures as optional-command failures.
- Added verification for ambiguous `MKD 550` responses before treating a directory as already existing.
- Applied the same verified directory creation path to manual and recursive-upload folder creation.
- Counted recursive traversal entries in addition to recursion depth.
- Added saturating aggregate transfer counters.
- Strengthened upload replacement with temporary remote files plus rollback backup behavior.

## Saved-profile hardening

- Normalized saved profiles before they enter application state.
- Removed duplicate Demo profiles and forced the retained Demo record back to canonical values.
- Invalid security modes fall back to FTPS Explicit.
- Invalid stored hosts are neutralized.
- Stored remote paths are canonicalized.
- Oversized profile strings/protected-password data are bounded or discarded.
- Decrypted saved passwords pass through FTP command-argument safety validation before use.

## Regression tests

Core self-tests cover forged/duplicate Demo profile data, invalid security/host/path state, oversized protected-password data and saved-password CR/LF injection.

## Release discipline

- Product identity remained Ghost FTP / GhostFTP.
- Version, assembly/file metadata and Windows manifests were synchronized to 1.3.1.
- Release remained gated on build, source/privacy/brand audit, Core tests, WPF input smoke tests, x64/ARM64 packaging and required executable checks.

## Historical note

Ghost FTP 1.4.0 later added the BRENDIGO LTD legal/publisher model, 29-language localization, guided Setup license flow, configurable retries/timeouts, server CWD/PWD synchronization and transfer-size integrity checks. Those later capabilities are not retroactively attributed to 1.3.1 binaries.
