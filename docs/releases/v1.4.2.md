# Ghost FTP 1.4.2

Release date: 2026-09-05

Ghost FTP 1.4.2 is a focused Windows Setup stability release.

## Fixed: installer crash when changing language

Ghost FTP Setup previously rebuilt its complete WPF wizard immediately from the language ComboBox `SelectionChanged` event while several stateful controls were still attached to the previous logical tree. Reusing those controls in the new tree could cause a fatal WPF reparenting exception as soon as the user selected another language.

1.4.2 changes the Setup rebuild lifecycle so that:

- reusable wizard controls are explicitly detached from their previous logical parents before a new visual tree is assembled;
- the language dropdown is closed before rebuilding;
- language-triggered rendering is deferred until the ComboBox input event has completed;
- repeated language changes are coalesced so overlapping rebuild requests cannot accumulate;
- a queued language rebuild is ignored after the Setup window has closed;
- normal wizard navigation continues to preserve state without reparenting the same controls illegally.

## New live Setup regression test

The Windows/WPF smoke test now references the real Ghost FTP Setup application and validates the actual wizard instead of testing only the localization dictionaries.

The test:

- opens the real Setup window on a Windows STA thread;
- finds the live Ghost FTP language selector;
- opens the dropdown and switches English → Croatian → German → Japanese → English;
- pumps the WPF Dispatcher after every change;
- verifies the selected locale remains active and the language selector stays attached to the rebuilt visual tree;
- clicks Next to move from Welcome to License;
- clicks Back to rebuild Welcome again;
- fails CI if Setup throws during any of those operations.

The smoke-test executable is self-contained so it can legitimately reference the self-contained Setup project during CI.

## Unchanged security and privacy model

This patch does not change FTP/FTPS protocol behavior, TLS validation, credential storage, transfer integrity, telemetry policy or networking behavior.

Ghost FTP remains free of application telemetry, analytics, advertising SDKs, tracking SDKs, crash-report upload, cloud profile sync and automatic background update checks.
