# Ghost FTP 1.2.0

Release date: 2026-09-05

Ghost FTP 1.2.0 focused on workspace usability, shared presentation architecture and operational consistency.

## Windows 11 workspace

- Reorganized the main window into a clearer page hierarchy: Saved Servers, global connection state, Quick Connect, Local / Remote panes and transfer queue.
- Added a shared `GhostFTP.Design` project used by both the desktop application and Setup.
- Centralized palette, typography, common controls, rounded surfaces and Windows DWM/Mica integration.
- Removed duplicated app/setup visual helpers.

## Quick Connect and server profiles

- Replaced anonymous connection fields with clearly labeled Host, Port, Security, Username and Password controls.
- Added reliable Enter-to-connect behavior from the password field.
- Improved saved-server navigation with explicit Add, Connect, Edit and Remove actions.
- Fixed profile matching so editing visible Quick Connect values cannot silently reuse incompatible Demo/saved-profile connection state.

## File management UX

- Added responsive wrapping file toolbars.
- Added dark/light-consistent GridView headers, selections, menus and tooltips.
- Added Local Home, Desktop, Documents and Downloads shortcuts.
- Added Remote root navigation.
- Added item/selection summaries.
- Added Copy path actions and Open in File Explorer for local files.
- Added optional hidden/system item visibility.
- Added keyboard shortcuts including F5, F2, Delete, Ctrl+F and Ctrl+L.

## Transfer queue UX

- Improved transfer status summaries.
- Kept queue work isolated from the browsing control session.
- Preserved cancellation and recursive transfer support.

## Setup UX

- Brought Setup/uninstall visuals into the same Ghost FTP design system.
- Added clearer inline progress and completion feedback.

## Maintainability

- Kept shipping source C#-only.
- Kept zero NuGet `PackageReference` runtime dependencies.
- Preserved self-contained x64 and ARM64 setup/portable packaging.

## Historical note

Later versions added stronger native editable-input regression tests, publisher metadata, localization and the guided license wizard. Those later changes are documented in their own release notes and do not alter the original 1.2.0 binaries.
