# Ghost FTP 0.1.7 Beta

Ghost FTP 0.1.7 Beta is a desktop quality, UI consistency and stability release for the native Windows/Linux FTP/FTPS client. It keeps the 0.1.6 safe-resume integrity model intact while correcting visual-state gaps, Linux window-state behavior and saved-site validation inconsistencies.

## Summary

This release focuses on finishing details that become visible during daily desktop use rather than expanding protocol scope. Windows receives clearer focus/selection states, improved responsive splitter feedback and a more coherent Site Manager. Linux now restores and persists its actual window dimensions, publishes an X11 minimum-size contract to the window manager, keeps the selected Light theme instead of silently returning to the canonical dark palette, and validates saved-site input before persistence.

The supported protocols remain FTP, Explicit FTPS and Implicit FTPS. Windows and Linux remain the only shipping application targets. Ghost FTP remains free of application telemetry/tracking and shipping/regression projects retain zero third-party NuGet `PackageReference` dependencies.

## Desktop design polish

### Windows

- Editable fields now expose a clear accent focus border and a stronger hover border without replacing the native WPF editor template.
- Selected ListView and ListBox rows receive a stable accent edge in addition to the existing soft selected background.
- Workspace splitters now provide visible hover feedback and localized resize/reset guidance.
- Tooltip width is bounded so long security or workflow guidance does not create impractically wide floating windows.
- Site Manager copy, section names and explanatory text now use the shared reference-shell English/Croatian copy with local English fallback for the remaining supported UI languages.
- Site Manager retains native/resizable window behavior and keeps its save/connect actions outside the scrolling content area.

### Linux

- Initial X11/XWayland window size now comes from the normalized local application settings instead of always opening at a hard-coded 1500×900 size.
- The final window width/height are persisted on normal shutdown and reused on the next launch.
- Ghost FTP publishes a 980×680 minimum window size through X11 WM normal hints, keeping the renderer geometry consistent with the supported minimum workstation layout.
- Light theme state is now preserved by the reference renderer both at startup and after saving Settings.
- Saved-site creation validates profile name, host, port, username and initial remote path before the profile is added to local storage.

## Shared reference-shell copy

The shared `GhostReferenceText` catalog now covers additional workstation guidance including:

- resize handles;
- local/remote double-click behavior;
- connection diagnostics status guidance;
- Site Manager sections and explanations;
- saved-site labels;
- TLS-first guidance.

Croatian has explicit local translations for these strings. All other configured languages continue to fall back to local English reference copy; no online translation lookup is introduced.

## Safe download resume model

The 0.1.6 safe download resume model remains unchanged and fully enforced:

- partial bytes stay in `.ghostftp.part` until verification succeeds;
- `.ghostftp.part.meta` binds resumable state to endpoint, security mode, remote path, `SIZE` and `MDTM` revision information;
- stale/untrusted partial cleanup fails closed;
- an existing destination remains untouched until remote post-validation succeeds;
- the dedicated resume-integrity regression suite remains a required Windows and Linux CI/release gate.

0.1.7 deliberately does not weaken or bypass any of those checks while changing desktop presentation or window handling.

## Security and privacy

- No telemetry, analytics, advertising, fingerprinting, cloud synchronization or background reporting was added.
- Saved-site input is validated before Linux persistence and remains normalized again in `ProfileStore` as a second boundary.
- Existing FTP command/path guards, FTPS certificate and hostname validation, `PBSZ 0`, `PROT P`, `TYPE I`, strict EPSV/PASV parsing, listing bounds, directory traversal bounds and safe resume rules remain unchanged.
- Password persistence remains opt-in and protected using the platform-specific local secret protection path.

## UI regression coverage

The WPF UI smoke suite now verifies shared reference-shell copy in addition to editable native controls, password input, security selection, the 29-language application/Setup catalog, product identity and Setup live language switching.

The reference-copy checks verify:

- required English workstation strings exist;
- Croatian reference strings are applied when Croatian is selected;
- a configured language without dedicated reference copy falls back to English locally;
- resize, Site Manager and TLS-first UI labels do not silently regress to raw localization keys.

## Known limitations

- Ghost FTP 0.1.7 remains Beta.
- SFTP/SSH is not implemented.
- Queue pause pauses dispatch only; it does not freeze an already-running FTP byte stream.
- Safe resume still requires usable `SIZE` and `MDTM` identity; otherwise interrupted downloads restart from zero.
- The Linux renderer remains an intentionally native X11/XWayland implementation rather than a third-party cross-platform UI toolkit.
- Windows and Linux remain the only shipping application targets.
