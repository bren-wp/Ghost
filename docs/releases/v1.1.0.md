# Ghost FTP 1.1.0

Release date: 2026-09-04

Ghost FTP 1.1.0 established the modern Windows client foundation.

## Highlights

- Rebuilt the client as a C#-only Windows desktop application.
- Added Windows 11-oriented Fluent/Mica visual treatment and a dual-pane Local / Remote workspace.
- Added a fully local Demo server with realistic folders and transfer behavior and no network activity.
- Added direct FTP, Explicit FTPS and Implicit FTPS support using the .NET networking stack.
- Added upload/download queueing, cancellation, recursive folders, rename, delete, new-folder and refresh operations.
- Added dedicated transfer FTP/FTPS sessions so queued transfers cannot desynchronize the browser control connection.

## Security and privacy

- TLS 1.2/1.3 support with normal certificate and hostname validation.
- No certificate-validation bypass setting.
- CR/LF/NUL command-argument guards.
- Remote path canonicalization and passive-host hardening.
- Recursive traversal limits and remote-root delete protection.
- NTFS reparse-point protection for recursive local operations.
- Optional saved passwords protected with Windows DPAPI.
- No application telemetry, analytics, advertising or tracking SDK.

## Persistence

- Added local saved-server profiles and settings.
- Added atomic profile/settings writes and recovery behavior.
- Password persistence remained opt-in.

## Packaging

- Added a per-user Windows Setup application.
- Added Start Menu/Desktop shortcut integration and Windows uninstall registration.
- Added self-contained x64 and ARM64 portable/setup builds.
- Added SHA-256 checksum generation.

## Validation

The 1.1.0 source line introduced Core self-tests and source auditing for dependency/privacy policy. Later releases strengthened these gates; those later improvements do not retroactively change the 1.1.0 binaries.

## Downloads

The historical release uses the release assets published for the 1.1.0 tag. Do not substitute binaries from newer Ghost FTP versions when verifying historical behavior.
