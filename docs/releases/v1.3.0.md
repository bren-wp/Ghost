# Ghost FTP 1.3.0

Release date: 2026-09-05

Ghost FTP 1.3.0 standardized product identity, strengthened installer/persistence safety and completed a major visual consistency pass.

## Product identity

- Standardized shipping product surfaces on **Ghost FTP / GhostFTP**.
- Added `GhostBrand` as the central runtime source for product name, website, repository and programmatic icon.
- Added the official vector icon under `assets/brand/ghostftp-icon.svg`.
- Added deterministic build-time generation of the Windows executable icon.
- Applied the icon to both the client and Setup executable resources.
- Added repository hero artwork under `assets/readme`.
- Added source auditing that rejects a return of previous non-Ghost FTP product identifiers.

## UI consistency

- Replaced remaining default Security/Appearance combo-box chrome with the shared Ghost FTP dropdown implementation.
- Applied the shared dropdown consistently across Quick Connect, server-profile editing and Settings.
- Removed obsolete visual helper paths after all callers moved to the shared design system.
- Polished sidebar branding, spacing and About navigation.

## Installer safety

- Added validation of the embedded application payload before installation.
- Required a plausible executable size and Windows `MZ` signature.
- Replaced existing installations using temporary files and atomic `File.Replace` semantics where supported.
- Made a locked/running Ghost FTP executable a visible Setup failure instead of a false success.
- Strengthened uninstall so required application deletion is verified.

## Persistence hardening

- Added a bounded settings file size.
- Added bounded profile file/backup sizes.
- Added a maximum saved-profile count.
- Added settings backup recovery and retained profile backup recovery.
- Preserved opt-in DPAPI-protected saved passwords.

## Security boundaries retained

- FTPS certificate and hostname validation.
- No certificate-bypass setting.
- FTP command-injection guards.
- Remote path canonicalization.
- Passive-host hardening.
- Recursive traversal limits.

## Build and release quality

- Removed stale hardcoded version fallbacks from About, Setup and uninstall metadata.
- Synchronized version metadata and Windows manifests for 1.3.0.
- Expanded source audits for required visual assets, shared design ownership and executable icon generation.
- Kept the shipping source dependency-free with zero NuGet `PackageReference` entries.
- Kept required x64/ARM64 `setup.exe` and `portable.exe` verification.

## Historical note

The BRENDIGO LTD publisher/legal model and the multi-language guided Setup wizard were introduced later in 1.4.0. This document describes the 1.3.0 release line and does not imply those later capabilities were present in 1.3.0 binaries.
